# PupLume Design Spec

## Overview
PupLume is an AI-powered puppy management app. The design language is bespoke, warm, editorial, and utterly friendly—eschewing generic "tech SaaS" aesthetics for something organic and grounded.

## Typography
- **Logo Wordmark:** `Grandstander` (800 weight). Completely rounded and bouncy, but retains elegant, sweeping flared finials (tails) on the `u`, `m`, and `e`.
- **Headings (H1/H2/H3):** `Grandstander`. Using heavier weights for a bold, bubbly, incredibly friendly hierarchy.
- **Body & UI:** `Grandstander`. Using lighter weights (400/500) to keep the app completely unified under one ultra-friendly, soft handwriting style.

## Colors
The palette is built entirely on warm earth tones and soft, non-sterile neutrals.
- **Backgrounds:** The primary app surface should lean towards `Cream` (#FFF9F2) rather than stark white.
- **Borders & Elevation:** Use `#E8DDD3` for borders, giving a soft, tactile feel.
- **Accents:** The brand primary is a warm bark brown (`#8B5E3C`), used for primary buttons and key interactions. Use `Sage` and `Peach` for success/warning states or secondary playful accents.

## UI Primitives
- **Elevation:** Cards should use a subtle, warm shadow: `box-shadow: 0 4px 12px rgba(44, 33, 27, 0.04)`.
- **Radii:** 
  - Elevated Cards: `1.5rem (24px)`
  - Primary Buttons: `1rem (16px)`
- **Scrollbars:** Custom slim scrollbars (`6px` width) with a fully rounded thumb using the `border` color.

## The Mark
The icon is a flat-vector, symmetrical, incredibly soft puppy face set against a cream background, featuring an asymmetrical yellow/peach sparkle to imply magic/AI.
